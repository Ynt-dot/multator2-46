# Интеграция внешнего API: DiceBear Avatars

## Выбор API

**DiceBear** — сервис генерации аватаров в формате SVG.

- Сайт: https://www.dicebear.com/
- Документация: https://www.dicebear.com/how-to-use/http-api/
- Лицензия: MIT (открытый исходный код)
- Стоимость: **бесплатно**, API-ключ **не требуется**

### Почему именно этот API?

Платформа Multator 2 ориентирована на аниматоров и художников. До интеграции пользователи без загруженного аватара видели текстовый fallback (первые две буквы имени).

DiceBear генерирует уникальные пиксельные аватары (`pixel-art` стиль) на основе username — детерминировано, то есть для одного и того же имени всегда возвращается один и тот же аватар. Это:
- Визуально лучше, чем текст
- Тематически подходит платформе (пиксель-арт = ретро анимация)
- Не требует регистрации и ключей
- Не нагружает собственную инфраструктуру (изображение отдаёт внешний CDN)

## Формат запроса

```
GET https://api.dicebear.com/9.x/{style}/svg?seed={seed}
```

| Параметр | Описание |
|---|---|
| `style` | Стиль аватара (`pixel-art`, `avataaars`, `shapes`, и др.) |
| `seed` | Любая строка — определяет внешний вид. Мы передаём `username`. |

**Пример:**
```
https://api.dicebear.com/9.x/pixel-art/svg?seed=kirillbarinov
```

Ответ — SVG-изображение, которое напрямую используется как `src` в `<img>` / `<AvatarImage>`.

## Что сработало

### 1. Простота подключения

Никакой авторизации, никаких заголовков. Достаточно сформировать URL — браузер загружает SVG как обычное изображение.

```ts
// lib/dicebear.ts
export function getDicebearUrl(seed: string, style = 'pixel-art'): string {
  const encodedSeed = encodeURIComponent(seed)
  return `https://api.dicebear.com/9.x/${style}/svg?seed=${encodedSeed}`
}
```

### 2. Плавный fallback без изменения логики компонентов

Функция `getAvatarUrl` принимает `username` и `avatar_url`. Если у пользователя есть загруженный аватар — возвращается он. Иначе — DiceBear URL:

```ts
export function getAvatarUrl(username: string, avatarUrl?: string | null): string {
  if (avatarUrl) return avatarUrl
  return getDicebearUrl(username)
}
```

Вместо:
```tsx
<AvatarImage src={profile.avatar_url || undefined} />
```
Теперь:
```tsx
<AvatarImage src={getAvatarUrl(profile.username, profile.avatar_url)} />
```

Radix UI's `AvatarImage` сам обрабатывает ошибки загрузки — если SVG по каким-то причинам не загрузится, отобразится `AvatarFallback` с текстом.

### 3. Места применения

| Файл | Место |
|---|---|
| `components/work-card.tsx` | Аватар автора в карточке работы |
| `components/header.tsx` | Аватар текущего пользователя в шапке / меню |
| `app/profile/[username]/page.tsx` | Большой аватар на странице профиля |

### 4. Детерминированность

Один username = один аватар всегда. Пользователь воспринимает его как «свой» аватар по умолчанию, что психологически лучше случайного изображения.

## Что не сработало / трудности

### 1. Next.js Image Optimization

Первоначально предполагалось использовать компонент `<Image>` из Next.js вместо обычного `<img>`, чтобы получить оптимизацию. Однако `next.config.mjs` уже содержит `unoptimized: true`, что отключает оптимизацию изображений для всего проекта. Отдельно добавлять домен `api.dicebear.com` в `remotePatterns` не потребовалось.

```js
// next.config.mjs — уже было в проекте
images: {
  unoptimized: true,
}
```

Если бы оптимизация была включена, потребовалось бы:
```js
images: {
  remotePatterns: [
    { protocol: 'https', hostname: 'api.dicebear.com' }
  ]
}
```

### 2. Кодирование seed

При использовании username с пробелами или спецсимволами (маловероятно, но возможно) URL сломается. Решение — `encodeURIComponent()`. Это было добавлено сразу в утилиту.

### 3. Зависимость от внешнего сервиса

DiceBear — внешний CDN. Если он недоступен:
- SVG не загрузится
- Radix UI `AvatarFallback` автоматически покажет текстовый fallback (первые буквы имени)
- **Ничего не сломается** — это задумано архитектурой Radix Avatar

Для production-уровня можно кешировать SVG или проксировать через Next.js API Route, но для данного проекта это избыточно.

### 4. Стиль `pixel-art` и цвет фона

DiceBear `pixel-art` по умолчанию генерирует аватар с прозрачным фоном. На светлых темах это выглядит хорошо, на тёмных — тоже, потому что пиксельные персонажи сами по себе контрастны. Дополнительная настройка не понадобилась.
